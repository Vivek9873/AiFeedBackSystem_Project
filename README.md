# Ai Feed Back System
- Tech Stack Used : Next.js, Css Modules, Open AI
- This app helps in identifying whether an audio is good or bad with the help of AI
# Features
- Can browse the audio file from the internal storage
- Can hear the audio with the help of audio player
- Can adjust the volume the audio
- Can get the ratings of audio with the help of AI
- Deployment Link https://ai-feed-back-system-project-p8p6.vercel.app/
